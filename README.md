# SocietyEvents

A modern web application for managing and organizing events within residential societies. Built with React, TypeScript, and Tailwind CSS.

## Features

- **Event Management**
  - Create and manage events
  - View event details
  - RSVP to events
  - Event calendar integration

- **Vendor Portal**
  - Vendor registration and management
  - Exhibition stall booking
  - Vendor dashboard
  - Revenue tracking

- **Venue Management**
  - Venue registration
  - Venue availability calendar
  - Amenities management
  - Image gallery
  - Pricing management

- **Community Features**
  - Community dashboard
  - Member profiles
  - Event discussions
  - Notifications

## Tech Stack

- **Frontend**
  - React 18
  - TypeScript
  - Tailwind CSS
  - React Router
  - Lucide Icons

- **Development Tools**
  - Vite
  - ESLint
  - PostCSS
  - Git

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/BuildAINilesh/societyevents.git
   cd societyevents
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.
